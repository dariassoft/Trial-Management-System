1. Instalar dependencias:
   $ cd tms-client-vue
   $ npm install

2. Configurar variables de entorno:
   $ cp .env.example .env.local
   (Usar valores por defecto si backend corre en localhost:3000)

3. Iniciar desarrollo:
   $ npm run dev
   Acceder: http://localhost:3001
