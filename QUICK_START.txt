### 🚨 SI ALGO FALLA

**Problema: Login muestra "undefined"**
```
Solución: Limpiar cache (Ctrl+Shift+Del) y reload
```

**Problema: "Cannot read properties of undefined"**
```
Solución: Verificar que utils/apiHelpers.ts existe
Ubicación: tms-client-vue/utils/apiHelpers.ts
```

**Problema: IndexedDB error**
```
Solución: Limpiar Storage (F12 > Application > Clear)
```

**Problema: Build falla**
```
Solución: rm -rf node_modules && npm install
Luego: npm run build
```
